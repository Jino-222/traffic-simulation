# 개발 도구와 검토 범위

## 제작 배경과 도구

교통영향평가 업무에서 신호 조건별 대안을 비교한 경험을 바탕으로, 합성 수요와 신호 배분을 비교하는 도구를 구성했습니다.

AI 개발 도우미를 코드 작성·수정, SUMO 실행, 자동 검사, 그래프·재생 구현과 결과 정리에 활용했습니다.

## 도구의 역할

| 도구 | 역할 |
|---|---|
| Python·Streamlit | 입력, 조건 검사, 화면과 실험 실행 연결 |
| Eclipse SUMO·TraCI | 차량·보행 이동 시뮬레이션과 실행 기록 |
| 그래프·영상 라이브러리 | 결과 시각화와 실제 궤적 재생 |
| AI 코딩 도구 | 코드 구현·수정·검증 작업 지원 |

학습형 AI 신호 제어 모델을 학습한 프로젝트는 아닙니다. 후보 순위는 계산값과 SUMO 실행 기록에서 정해집니다.

## 추가 실무 검토

- 가상 도로·신호·수요와 현장 조건의 차이
- 입력 조건을 바꿨을 때 예상과 실행 결과의 차이
- 전체 평균과 특정 방향의 불이익 사이의 판단
- 미진입·미완료 차량이 남은 결과의 해석
- 실측 자료를 확보한 뒤 필요한 보정과 별도 검증

이 검토는 자동 검사 통과와 구분합니다. 현장 타당성·교통안전·공식 LOS 검증은 미실시 상태입니다.

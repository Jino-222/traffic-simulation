# 기여와 수행 확인

## 확인된 기여

| 주체 | 현재 확인 가능한 기여 |
|---|---|
| 동생 | 사용자가 전달한 도시계획·교통영향평가 업무 경험과 상사와의 대안 비교 사례가 문제 정의의 출발점입니다. |
| 형(사용자) | 실무 경험을 최근 AI 활용 프로젝트로 연결하는 방향 제안, 연구 질문과 비교 범위·검증 조건·포트폴리오 목적을 제시했습니다. |
| AI 개발 도우미 | 코드 작성·수정, SUMO 실행, 자동 테스트, 그래프·재생 구현, 공개 자료 취득·검사, 실행 결과 정리를 수행했습니다. |
| SUMO 및 외부 라이브러리 | 차량·보행 이동 시뮬레이션, Python 웹 화면, 그래프, 영상 인코딩의 기반을 제공합니다. 해당 엔진을 직접 개발한 것으로 표현하지 않습니다. |

## 아직 확인되지 않은 활동

동생이 직접 코드를 작성했다거나 특정 실험을 실행·검토했다는 사실은 현재 기록으로 확인하지 않았습니다.
형이 직접 작성한 코드나 실행한 테스트도 확인된 범위 외에는 기여로 기록하지 않습니다.

## 동생이 직접 검토한 뒤 남길 기록

- 검토 날짜와 선택한 실험 ID.
- 실무 경험과 다른 가정, 이유, 수정 제안.
- 입력을 직접 바꾼 내용과 예상한 결과.
- 실제 결과와 예상이 달랐던 부분.
- 전체 평균과 특정 방향의 불이익 중 무엇을 중시했는지.
- 수행한 작업, 도움받은 작업, 이해하지 못한 부분.
- 실제 회사 자료를 사용하지 않았다는 점과 합성 실험의 한계.

이 항목은 이후 직접 수행을 기록하기 위한 양식이며, 현재 수행 완료를 뜻하지 않습니다.

# 확장 연구 진행 기록 · 공개 자료와 보행 형상

전체 목표는 계속 진행 중이다. 좌·우회전·다중 교차로, 대기행렬 추가 검증, 전체 기능의 최종 사용성·배포 산출물 점검이 남아 있다.

## 이번에 완료한 실행과 검증

- 기존 31개 신호 배분 × 3시드 탐색과 고정 후보 별도 시드 검증에 이어, 시나리오 16개 × 입주 전·후·후보 3상황의 48회 실행이 끝났다.
- 해당 일괄 실행은 모든 항목에 불규칙 도착을 적용하므로 baseline과 irregular가 동일 설정이었다. 두 행을 독립 근거로 계산하지 않도록 보고서를 수정하고 규칙 도착 대조 실험 3회를 추가했다. 동일 방향별 총량과 도착 방식만 다른 조건임을 검사했다.
- 모든 시나리오에서 수요 파일 해시, 차량 집계 항등식, 신호·보행 이상·충돌·순간이동을 검사했다. 교통량 0대에서 평균값은 해당 없음으로 처리됐다. 높은 수요의 미처리 차량은 그대로 기록했다.
- 공개 NGSIM 연속 추종 표본에 Krauss 24개 매개변수 조합을 실행했다. 보정 대상 11대에서 선택을 고정한 뒤 다른 대상 10대에서 비교했다. 기준 조합이 선택돼 추가 개선은 확인되지 않았다.
- 검증 차량별 RMSE 평균은 속도 1.253120m/s·차간격 3.569642m다. 전체 프레임을 합친 RMSE와 구분한다. 강제 앞차의 원자료 잡음 및 급제동 경고, 작은 동일 장소 표본과 연결된 차량 관계의 한계를 공개했다.
- 공개 자료 실험의 종료 차량 구독 해제 누락을 수정했다. 첫 실행의 오류 로그와 소스는 public_calibration_v1에 보존하고, 수정한 v2에서 24개 조합과 기준·선택 검증을 모두 재실행했다. 결과값은 같다.
- 뒤차의 미래 관측값을 바꿔도 SUMO 예측은 같다는 통합 테스트로 관측값을 매 단계 정답으로 되먹이지 않음을 확인했다.
- 차로 수 1~4, 보행속도 0.7/1.0m/s의 8개 보행시간 경계 검사를 통과했다. 3개 형상 사례 × 3상황 총 9회 실행에서 매회 보행자 12명 완료, 네 횡단보도 사용, 신호 진입·점유 이상 0건을 확인했다.

## 화면과 내보내기

- 심화 연구 화면에 공개 자료의 후보 곡선, 검증 차량별 오차, 선택 차량 속도·간격 그래프, 보행 형상 표·그래프를 추가했다.
- 기본 교차로 합성 결과와 공개 실측 자료 연구의 범위를 구분했다.
- 그래프 제목과 범례가 겹치는 배치를 수정했다. 이미지 내보내기의 투명 배경이 어두운 뷰어에서 글자를 가리는 문제를 흰 배경으로 수정했다.
- 390×844 화면에서 접힌 사이드바가 45px 남아 본문을 가리는 문제를 발견했다. 고정 sidebar 폭 CSS를 제거하고 상단 여백을 조정해 수정했다.
- 실제 브라우저에서 차량 선택, 공개 자료·보행 검증 화면, CSV·PNG 다운로드를 확인했다. 다운로드 CSV SHA-256은 원본과 일치했다. 브라우저 오류 로그는 없었다.
- 전체 실험 ZIP에서 누락됐던 압축 FCD(.gz) 파일을 포함하도록 수정했다. 최종 ZIP 다운로드·압축 해제 종단 검사는 아직 필요하다.

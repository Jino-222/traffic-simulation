통행 완료 87대 증가

동일한 1,355대의 출발 요청 중 완료 차량은 1,086대에서 1,173대로 늘었습니다. 종료 시 미진입 차량도 123대에서 39대로 줄었지만, 여전히 143대는 통행 중이었습니다.

‘전반적 개선’으로 단정하지 않기

완료 차량의 평균 timeLoss는 193.62초에서 197.76초로 증가했습니다. 완료 차량 구성도 달라졌으므로, 완료 차량 평균만으로 모든 차량의 개선 효과를 판단할 수 없습니다.

REPRODUCIBILITY & LIMITS

이 실험이 말해 주는 범위.

실제 도로 위에서 합성 수요를 비교하는 시각화 실험입니다. 현장 교통영향평가나 실제 신호 운영을 대체하지 않습니다.

01 / 데이터

OSM 도로·건물 평면, 중심 35.8591365°N / 128.6262151°E. 기본 수요 북 400 · 남 450 · 동 900 · 서 900대/시, 입주 추가 수요 남측 600대/시. 실제 아파트 사업·교통량 자료가 아닙니다.

02 / 실행 조건

SUMO 1.28, seed 2026. 수요 생성 0–1,500초, 준비 300초, 관측 300–1,500초, 종료 2,100초. 기본 신호는 자동 생성, 조정안은 동일 90초 주기에서 녹색 16/12/21/17초.

03 / 지표 해석

도로 평균속도는 차량 체류시간으로 가중했습니다. 정지 기준은 0.1m/s 미만. timeLoss는 완료 차량만 포함하며 미완료·미진입 편향이 있습니다. 회색 도로는 차량 관측이 없는 곳입니다.

04 / 아직 확인할 것

OSM 차로·회전 연결·자동 신호의 현장 검증, 보행자와 횡단시간, 버스 실제 노선, 다중 시드, 수요 보정이 필요합니다. 버스·트럭은 형상/길이만 구분하고 passenger 통행 권한을 사용했습니다.
